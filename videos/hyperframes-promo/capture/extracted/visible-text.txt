[h1] What is HyperFrames?
[span] Copy page
[p] See what an AI agent can make with ordinary web technology.
[span] Copy page
[span] HyperFrames is an open-source framework that turns HTML into video. You make the request; an AI agent builds an editable project; HyperFrames plays or renders it.

[span] Three things to know
[strong] Agent-built.
[span] You describe the video; the agent writes the HTML, CSS, and JavaScript. You do not need to write code for this path.
[strong] Editable.
[span] The result is a project folder, not a flattened black box. An agent, Studio, and your own tools can work on the same files.
[strong] Reliable render.
[span] HyperFrames asks the project for each exact frame instead of
depending on live playback, so a slow machine does not drop moments from the
finished video.
